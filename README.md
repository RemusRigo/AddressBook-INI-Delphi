# AddressBook-INI
AddressBook-INI: an address book that saves each contact in an .ini file



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* One `.ini` file per contact, in the `Contacts` folder
* Contact list, add and edit contacts
* Alarm: a monthly calendar with the contacts' birthdays (also with the `/alarm` command line switch)
* Options: user interface language (from the `Language` folder)
